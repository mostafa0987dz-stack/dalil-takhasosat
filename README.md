# دليل التخصصات الجامعية الجزائرية

## التشغيل المحلي
1. ثبّت Node.js 18.17 أو أحدث.
2. فك ضغط المشروع ثم نفّذ:
   ```bash
   npm install
   npm run dev
   ```
3. افتح http://localhost:3000

## النشر على Vercel
ارفع المشروع إلى GitHub ثم استورده من Vercel. إعدادات البناء الافتراضية مناسبة لـ Next.js.

## البيانات
عدّل `data/specialties.json` لإضافة التخصصات. الأرقام الموجودة في `seuil_2025` تجريبية/توضيحية وليست بيانات قبول رسمية.

## ملاحظات قبل الإنتاج
- الحاسبة الحالية تحسب متوسطاً حسابياً بسيطاً، وليست المعدل الموزون الرسمي. أضف معاملات رسمية موثقة لكل تخصص وشعبة.
- تحقق من شروط الالتحاق والجامعات والعتبات من منشور التوجيه السنوي لوزارة التعليم العالي.
- يمكن إضافة اختبارات، نظام إدارة محتوى، وتصدير PDF لاحقاً.
